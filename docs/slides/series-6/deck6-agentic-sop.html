각 단계는 FAIL 시 멈추지 않는다 — 그 단계의 전문가 AI가 붙고, 수정 후 그 단계로 재진입(Retry)한다.
다섯 단계는 결정론적이다 — 같은 입력엔 같은 순서, 같은 실행. 다섯이 모두 통과해야 — 사람의 리뷰로 넘어간다.

05 / 08
실패하면, 누가 고치나
범용 AI 하나가 아니라 — 단계별 전문가.
① BUILD
Build Expert
  • Compiler Error 분석
  • Dependency 문제
  • Build Script 검토
  • Config · 환경 진단
② UNIT
Unit Test Expert
  • Assertion Failure
  • Mock · Stub 문제
  • Logic 버그 탐지
  • Test Coverage 확보
③ INTEGRATION
Integration Expert
  • Interface Mismatch
  • Contract · Schema 검증
  • Module Dependency
  • 연동 문제 진단
④ TARGET
Target Test Expert
  • Device Log 분석
  • FW · OS 환경
  • Hardware Interaction
  • Domain Rule · Spec
⑤ PERF
Performance Expert
  • Latency 분석
  • Throughput 분석
  • CPU · Memory
  • I/O Bottleneck
각 단계의 FAIL은 — 그 단계를 가장 잘 아는 전문가 AI에게 간다. 한 명의 만능이 아니라, 다섯의 전문성이다.
