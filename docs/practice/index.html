실습자료

읽고 끝내지 않는다. 템플릿 레포를 직접 복제해 HALO 워크플로우와 영상 에이전트를 손으로 돌려보고, 한 걸음 더 들어가 "규칙 기반에서 판단 기반으로" — 에이전트의 본질까지 짚는다.

#rule-to-reasoning #agent #automation #concept

시작하기 전에

두 레포 모두 Claude Code 템플릿이다. GitHub에서 “Use this template” 버튼으로 자신의 독립된 레포를 만든 뒤(fork 아님) 복제해서 진행한다. 공통 준비물은 다음과 같다.

  • Claude Code — 두 레포의 .claude/ 에이전트·워크플로우를 실행하는 핵심 도구
  • Git — 레포 복제 및 체크포인트 관리
  • Node.js 18+ — 영상 트랙(oh-my-vedioagent)에서만 필요
  • LLM API 키 + 결제 등록 — 트랙 W(글쓰기 에이전트 LLM API)에서만 필요. 에이전트가 글을 쓰고 평가하는 모든 판단이 유료 LLM API 호출로 일어나므로, 결제 수단이 등록된 API 키(예: Anthropic·OpenAI)가 있어야 실제로 돌아간다.

설치와 로그인이 처음이라면 시작하기 — 설치와 로그인부터 따라 한다. Claude Code를 깔고 계정으로 로그인하는 공통 준비를 한 번에 끝낼 수 있다. 그다음 각 트랙 페이지의 단계별 명령으로 넘어가면 된다 — 원하는 트랙부터 시작한다.
