설치와 로그인Claude Code · 모든 트랙 공통 준비

트랙을 고르기 전 설치 → 로그인만 끝내면 된다. 아래는 Windows · PowerShell 기준(관리자 권한 불필요).

1. Claude Code 설치 — 필수

irm https://claude.ai/install.ps1 | iex

새 터미널에서 claude --version으로 확인. (macOS·Linux: curl -fsSL https://claude.ai/install.sh | bash)

2. 로그인 — 필수

claude

브라우저가 열리면 이메일 로그인을 골라 배포받은 이메일을 입력하고(구글 아님), 메일로 온 인증 코드를 넣으면 끝. 개인 계정이 아니라 안내받은 이메일이어야 한다.

3. Git 설치 — 권장

winget install --id Git.Git -e

4. VS Code 설치 — 권장

winget install --id Microsoft.VisualStudioCode -e

폴더를 열고(File → Open Folder) Ctrl + `로 터미널을 띄워 그 안에서 claude를 실행한다.
