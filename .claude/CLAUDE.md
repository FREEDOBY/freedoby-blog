# 슬라이드 deck 작성 규칙

발표 자료(`docs/slides/**/deckN-*.html`)를 만들거나 수정할 때는
**반드시 `.claude/rules/deck-style-guide.md`를 따른다.** 기준 구현체는 `docs/slides/series-3/deck3-evolution.html`.

핵심 (상세는 가이드 참고):

- **글자 크기는 14px 이상.** (모든 텍스트·캡션·표 셀)
- **페이지 번호 `NN / TT`** 는 chrome·foot·표지에 모두. 슬라이드 추가/병합/삭제 시 분모와 이후 번호를 전부 갱신.
- **의미색 고정**: Vendor=골드 `--gold`, User=파랑 `#8fb2cc`, 대화/중립=`--muted-lt`. 한 개념은 deck 전체에서 한 색.
- **색·폰트는 `:root` 토큰만.** 임의 hex·원색 금지.
- **톤**: 짧고 단정한 한글 + 일관된 영문 용어 + em-dash 리듬. 1인칭은 "우리".
  - 금지: 목차/내비 메타("N번 이후…"), 읽는 법 해설("막대는 X, 표는 Y"), 가변값을 고정처럼 단정, 반말("너/네").
- 같은 섹션·같은 배경의 풀스테이지 슬라이드는 제목 요소(kicker/keyword) 통일.
- 수정 후 브라우저로 실제 렌더 확인.
